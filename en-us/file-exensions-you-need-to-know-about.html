File Extensions You NEED To Know About

Terminology: Lossy - The file loses quality when edited Lossless - The file doesn't lose quality when edited Audio: .mp3 - MP3 audio (lossy) .ogg - Ogg Vorbis audio (lossy) .wav - WAV (lossless) .wma - Windows Media Audio audio (lossy) Video: .mkv - Matroska Multimedia Container .mp4 - MPEG4 .mov - Apple QuickTime .webm - WebM .wmv - Windows Media Video Image: .bmp - Bitmap (lossy) .gif - Graphics Interchangable Format (lossy, animated) .ico - Icon .jpeg / .jpg - Joint Photographic Experts Group (lossy) .png - Portable Network Graphics (lossless) .webp - WebP (lossy) Compressed Files: .7z - 7-Zip .rar - RAR .tar.gz - Tarball .zip - ZIP Executable: .bat - Batch .cmd - Command Prompt .exe - Windows Executable .msi - Windows Installer Package .sh - Linux Shell Script Spreadsheet: .ods - OpenOffice Calc .xls - Microsoft Excel (97 ~ 2003) .xlsm - Microsoft Excel (with macros) .xlsx - Microsoft Excel (2007 ~ current)
