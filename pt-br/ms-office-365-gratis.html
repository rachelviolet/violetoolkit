O Pacote Microsoft Office e como conseguí-lo gratuitamente.

O pacote Microsoft Office é uma das aplicações mais usadas no mundo moderno. Lançada em 19 de novembro de 1990, o Microsoft Office é uma ferramenta popular instalada em computadores pessoais e de trabalho ao redor do mundo.

Alguns produtos atualmente incluídos no Microsoft office / Microsoft 365 incluem:

  • Microsoft Access
  • Microsoft Copilot
  • Microsoft Excel
  • Microsoft Lists
  • Microsoft OneDrive
  • Microsoft OneNote
  • Microsoft Power BI
  • Microsoft PowerPoint
  • Microsoft Sway
  • Microsoft Teams
  • Microsoft Word

    • Com essas aplicações, você pode criar apresentações, planilhas eletrônicas, documentos e muito mais! O pacote Microsoft Office é uma única compra, já o Microsoft 365 é um serviço baseado em assinaturas. Apesar de existir outras alternativas gratuitas de código aberto, como o LibreOfficed, há uma maneira de usar o Microsoft 365 de graça.

    Acessando o Site oficial da Microsoft 365 para a Web, você pode utilizar alguma dos recursos e ferramentas da versão paga do Microsoft 365 em seu navegador.
