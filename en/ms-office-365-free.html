Microsoft Office apps and how to use them for free.

The Microsoft Office suite is one of the most used applications in the modern world. Released in November 19, 1990, Microsoft Office is a popular tool installed on personal and work computers all around the world.

Some products currently included in Microsoft Office / Microsoft 365 include:

  • Microsoft Access
  • Microsoft Copilot
  • Microsoft Excel
  • Microsoft Lists
  • Microsoft OneDrive
  • Microsoft OneNote
  • Microsoft Power BI
  • Microsoft PowerPoint
  • Microsoft Sway
  • Microsoft Teams
  • Microsoft Word

    • With those applications, you can create presentations, spreadsheets, documents, and much more! The Microsoft Office suite is a one-time purchase, while the Microsoft 365 is a subscription-based service. Although there are other free and open source alternatives, like LibreOffice, there is a way to use Microsoft 365 for free.

    By accessing The official Microsoft 365 for the Web website, you can use some of the features from the paid version of Microsoft 365 on your browser.
